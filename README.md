# MusicInformation

OBS の配信画面に、曲名とアーティスト名・アルバム名を表示するための小さな Web アプリです。テキストファイルを書き換える手段を用意すれば、音楽情報を配信画面に表示できます。

## 主な機能

- 曲名とアーティスト名・アルバム名を別々に表示
- テキストファイルを1秒ごとに読み込み、変更を自動反映
- 表示幅を超える長いテキストを横スクロール
- 短いテキストはスクロールせず、そのまま表示
- スクロールアニメーションの全体時間・待機時間・スクロール時間を設定
- デバッグモードで表示領域の開始位置と終了位置を確認
- フォント、文字サイズ、色、幅、左余白を設定ファイルで調整
- 任意のフォントファイルを指定して読み込み

## 必要なもの

- OBS Studio（ソース:ブラウザを使用）
- `MusicInformation.html` と設定・テキストファイルを HTTP 経由で配信できる環境

ビルドツールやパッケージのインストールは不要です。設定とテキストはブラウザの `fetch` で読み込むため、HTML ファイルを直接開くのではなく HTTP 経由でアクセスしてください。

## インストール・起動（OBSで使用する場合）

1. このリポジトリをクローンするか、Code から Download ZIP をクリックしてダウンロードします。
2. プロジェクトのファイル一式を、任意の場所へ配置します（ZIPファイルは解凍しておきます）。
3. OBS の「ソース」で「ブラウザ」を追加し、ローカルファイルへチェックを付けてから、`MusicInformation.html` の保存場所を指定します。
4. 必要に応じて、ブラウザソースの幅と高さを調整します。

HTTP サーバーの用意や OBS の操作方法は、利用する環境に合わせて設定してください。

## 使い方

表示内容は次のテキストファイルに UTF-8 で保存します。

- 曲名：`txt/Title.txt`
- アーティスト名・アルバム名：`txt/Artist_Album.txt`

各ファイルに表示したい文字列を書き込んで保存すると、通常は1秒以内に画面へ反映されます。テキストファイルを書き換える手段は、用途に合わせて用意してください。両方の表示欄は独立しており、長い文字列は自動で横スクロールします。

## 表示のカスタマイズ

設定ファイルはプロジェクトのルートにある `config.json` です。

`title` と `artistAlbum` それぞれに、次の項目を設定できます。

| 項目          | 説明                                                                                                                                    |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `file`        | 表示内容を読み込むテキストファイルの相対パス                                                                                            |
| `width`       | 表示欄の幅（ピクセル）                                                                                                                  |
| `font`        | フォント名                                                                                                                              |
| `fontFile`    | フォントファイルの相対パス                                                                                                              |
| `fontWeight`  | フォントの太さ（[OpenType `usWeightClass` の説明](https://learn.microsoft.com/ja-jp/typography/opentype/spec/os2#usweightclass)を参照） |
| `fontsize`    | 文字サイズ（ピクセル）                                                                                                                  |
| `color`       | 文字色（CSS の色指定）                                                                                                                  |
| `paddingLeft` | 左余白（数値または CSS の値）                                                                                                           |

### マーキーアニメーションの設定

`config.json` の `marquee` で、横スクロールの時間を設定できます。

時間の単位は**秒**です。小数も指定できます（例：`2.5` は2.5秒）。

| 項目             | 説明                          |
| ---------------- | ----------------------------- |
| `totalDuration`  | アニメーション1周期の全体時間 |
| `waitDuration`   | スクロール開始までの待機時間  |
| `scrollDuration` | 実際にスクロールする時間      |

`totalDuration` は `waitDuration` と `scrollDuration` の合計にしてください。

初期設定は、全体15秒・待機5秒・スクロール10秒です。

設定例：

```json
"marquee": {
  "totalDuration": 15,
  "waitDuration": 5,
  "scrollDuration": 10
}
```

### デバッグモード

`config.json` の `debug` で、表示領域の目印を表示するかどうかを切り替えられます。

- `True`：デバッグ表示 ON
- `False`：デバッグ表示 OFF

文字列で指定する場合、大文字・小文字は区別しません（例：`"True"`、`"TRUE"`、`"true"`）。

また、JSON の真偽値 `true` / `false` も使用できます。

デバッグ表示を ON にすると、`title` と `artistAlbum` の表示領域に次の目印が表示されます。

- 緑：表示領域の開始位置（左端）
- 赤：表示領域の終了位置（右端）

目印は表示領域に重ねて描画されるため、テキスト幅の計測やスクロール判定には影響しません。

通常の配信時は `False` にしてください。

JSON の形式を保ち、ファイル名の大文字・小文字も実際のファイル名と一致させてください。設定例は `config.json` を参照してください。

## ファイル構成

```text
MusicInformation.html   表示ページ
marquee.js              設定・フォント・テキストの読み込みと表示処理
style.css               レイアウトとスクロールアニメーション
config.json             基本設定
txt/
  Title.txt             曲名
  Artist_Album.txt      アーティスト名・アルバム名
fonts/                  フォントファイルの配置先（任意）
```

フォントファイルは必須ではありません。使用する場合は `fonts/` などに配置し、設定の `font` と `fontFile` を指定してください。
